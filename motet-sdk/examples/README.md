## Directory: examples

**SDK example bundles** shipped beside the source tree (not installed as a separate distribution).

### Layout

| Path | Contents |
|------|----------|
| **`bundles/`** | Example Motet bundles (`manifest.yaml`, commands, tools, workflows, agents). See **`bundles/README.md`** for an index. |

### Notes

Regression and intentionally broken fixtures live under **`tests/bundles/`** in the main Motet repo, not here.
